pub fn dir_name_from_url(url: &str) -> Result<String, Error>
Expand description

像 git 那样，从远程 URL 推导出本地目录名。

规则：去掉末尾的 /，取最后一段路径（/ 或 scp 风格的 : 之后）， 再去掉末尾的 .git 后缀。例如：

  • https://github.com/foo/bar.git → bar
  • git@github.com:foo/bar.git → bar
  • https://example.com/baz/ → baz
