返回两个 commit 的最近公共祖先（merge base）。

  • 两个 commit 相同：直接返回该 OID。
  • 一方是另一方祖先（fast-forward）：返回那个祖先。
  • 分叉历史：返回 BFS 拓扑序中最先从 B 侧发现的 A 侧祖先。
  • 多个 LCA（criss-cross）：返回其中之一（resolve 策略，不做递归虚拟合并）。
  • 完全不相关的历史：返回 None。
