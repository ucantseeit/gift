落盘半部（与 clone_to_disk 对位）：把内存里的对象写进已存在仓库的 对象库，并更新远程跟踪引用 + FETCH_HEAD。不碰 HEAD / 本地分支 / 工作区。

git_abs 是已存在仓库的 git 目录绝对路径（如 .../.gift；测试里传 .git）。
