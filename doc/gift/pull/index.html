git pull = fetch + merge。完全复用已有两块：

  • crate::fetch::fetch：拉对象 + 更新 refs/remotes/<remote>/*（不动工作区）
  • crate::merge::merge：把抓到的远程分支并入当前分支（FF / 三方 / 冲突）

简化点：本项目没有 remote / upstream 配置系统，所以远端 url 显式给出； 要并入的远程分支默认取“当前 HEAD 所在分支的同名远程分支”，也可显式指定。

拆成两层是为了可测：pull = fetch + merge_remote_tracking，后者（fetch 之后 的纯本地“并入”逻辑）不依赖网络，可离线测试。
