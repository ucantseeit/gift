fetch 之后的“并入”部分（纯本地）： 解析要并入的远程分支 → 读 refs/remotes/<remote>/<branch> 的 OID → 调 merge。

branch 为 None 时取当前分支同名。target 传 40 位 hex OID，merge 直接解析， 无需把远程分支写进 refs/heads/。
